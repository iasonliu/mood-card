# 🎭 MoodHand 每日手绘心情卡片

> 基于手绘算法与 VideoHand 视觉规范构建的每日治愈手账卡片生成器。

## ✨ 特性

- 🎨 **手绘矢量风格**：全套手绘笔触算法（Multi-pass Wobbly Engine）+ 纯 SVG 矢量图标。
- 🎭 **丰富小人形象**：6 种发型头饰（呆毛/贝雷帽/头戴耳机等）、3 种服饰、5 种情绪神态与手持道具（咖啡杯/气球/放大镜等）。
- 📝 **手账卡片体系**：
  - 动态能量仪表槽（Energy Meter）
  - 今日治愈小事打卡清单（Hand-drawn Checklist）
  - 4 种纸张底纹切换（方格/点阵/横线/留白）
  - 5 款复古手账色板（松绿/砖红/靛蓝/落日/暮紫）
- 🔊 **拟真手绘音效**：Web Audio API 纯代码合成清脆交互动效。
- 📸 **高保真导出**：支持 3x Retina 拍立得卡片一键保存。
